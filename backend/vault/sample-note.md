## Current Projects

### Obsidian RAG — AI Second Brain
A local-first AI assistant built on top of an Obsidian vault. The system retrieves relevant note chunks using semantic search (Qdrant + nomic-embed-text) and synthesizes answers using a local LLM (Ollama + qwen2.5). Built with FastAPI, LlamaIndex, and a custom prompt engineering layer with citation formatting and token-aware context truncation.

**Tech stack:** Python, FastAPI, Qdrant, Ollama, LlamaIndex, nomic-embed-text, qwen2.5
